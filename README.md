\# EDGE-DRIVE



Edge-Optimized Disaster Risk \& Intelligent Relief Engine



\## Problem

Disaster response in flood-prone regions suffers from delayed risk assessment and inefficient relief distribution.



\## Solution

An AI-powered system that:

1\. Detects flood severity from satellite imagery

2\. Computes population risk overlay

3\. Optimizes relief allocation

4\. Benchmarks CPU vs GPU performance for edge deployment



\## Architecture

Flood Segmentation → Risk Engine → Relief Optimizer → Hardware Benchmarking



\## Tech Stack

\- PyTorch

\- NumPy

\- OpenCV

\- NetworkX

\- Streamlit
